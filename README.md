# Banco_Hospital
Banco hopital
Hospital – Banco de Dados   desenvolver e organizar um banco de dados para o sistema hospitalar **Kyris Hospital**, visando otimizar o gerenciamento de informações e contribuir para a eficiência dos processos administrativos e operacionais.  O projeto contempla a estruturação e o relacionamento de dados relacionados a pacientes, médicos, funcionários, consultas, internações e demais informações essenciais para o funcionamento de uma instituição hospitalar.  O desenvolvimento busca 
aplicar conceitos fundamentais de Banco de Dados, como modelagem, organização, integridade e relacionamento entre tabelas,
proporcionando uma estrutura eficiente, segura e consistente.  **Kyris Hospital – Tecnologia e organização a serviço da saúde.*
